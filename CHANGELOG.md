# Changelog

## 0.1.0 — October 26, 2026

First public School in a Box starter kit, adapted from the DABA learning-through-teaching project.

- Two Amdo–English weeks with eight editable teacher/student lesson files and four level tags.
- Four adaptable campus contexts and six human-led school planning templates.
- Offline library with search, course/week/level/language filters, printable documents, browser-local notes and reviewed import/export.
- Dependency-free Python server, static site builder, reproducible offline ZIP, checksums and ten standard-library tests.
- MIT software, CC BY 4.0 educational content, contribution guidance and public roadmap.

Local tests and Chromium browser flows passed. Multi-version CI is supplied as an example configuration; credentials did not permit installing an Actions workflow. Source language and pedagogy remain drafts awaiting qualified educator review. The 36-week course and autonomous campus operations are not implemented by this release.
