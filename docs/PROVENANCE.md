# Provenance and publication scope

This starter kit was established on October 26, 2026 from the owner's DABA (Dzokden-Amdo Bilingual Academy) learning-through-teaching project. The owner requested a public open source “school in a box” project, with the course and campus system in mind.

The private recovery found fourteen documents: eight week 1–2 lesson/answer-guide files and six architecture/planning documents. An inventory claimed a broader assembled system, but no runnable database, full-year curriculum, agent fleet, campus networking scripts or deployed school was established by that recovery.

This public repository contains an adapted edition of the eight lessons, a reusable reading portal, and newly written campus/course/setup templates. Original religious text excerpts and unsupported historical attributions were omitted or replaced by peer-teaching reflection prompts. The original private recovery remains separate. This project does not claim authority to license an external author's text, religious corpus, or institutional name.

Private Google Drive object identifiers, links, operational receipts, personal study notes, local machine paths, proposed travel/launch details, and governance/credential bindings are not distributed. Public paths and content IDs are project-local. Educational files carry a draft review status; published software tests are not evidence of pedagogical, linguistic, institutional or legal approval.

No endorsement, campus operation, accreditation, learner outcomes, regulatory compliance, or association with an institution is asserted. The name DABA identifies the source project; downstream users can replace it and the campus configuration.

Publication grants: MIT for software/technical docs; CC BY 4.0 for project-authored educational content. New contributions must state provenance and compatible permission. Review claims should be added only after actual scoped review, with reviewer consent.
